To complement this mathematical approach, we also computed simulations tracking performance on quantum algorithms as we varied temperature as the single control parameter. We computed simulations of both:
\begin{itemize}[itemsep=1pt]
	\item Full quantum circuits, tracking full density matrix representations, allowing us to employ full Qiskit noise models
	\item Circuits using only Clifford gates, tracking qubit state using stabiliser states and only employing simpler Pauli noise models. This allowed us to simulate much larger numbers of qubits.
\end{itemize}

\subsection{Preface of Result Validity}

The validity of these results hinges primarily upon the correctness of the code used to generate them. Thus, we have generated an extensive suite of unit tests to ensure the framework is operating as expected.

Moreover, the validity and applicability of these results further hinges upon the use of correct and properly catalogued assumptions used to generate them. We employ the following to mitigate the risks of compromising these qualities:
\begin{itemize}[itemsep=1pt]
	\item The use of a variety of different methods of producing results, including a variety of different metrics and methods of generating noise models. These methods vary in complexity and specificity, avoiding how many assumptions are universally relied upon.
	\item Comprehensively cataloguing the assumptions used at every stage of generating the results, including how they change for each method of producing results.
\end{itemize}

To do this, we treat each set of results as a case study. Because there is so much overlap between the assumptions of each case study, we include a set of all set of assumptions in the appendix, and specify which ones apply for each.

There are a few assumptions that due to the inherent limitations of the simulation architecture universally apply, and are worth pointing out separately:

\begin{itemize}
	\item All noise models are inherently gate-local (and thus also qubit-local)
	\item All noise models are state independent and unchanging over time throughout the whole metric simulation, and every shot and trial of the metric
	\item All noise models are Markovian
\end{itemize}

For all further assumptions, reference specific assumption sets on a per case study basis. The theory behind some of the assumptions is listed in the third subsection.

\subsection{Assumptions}

\subsubsection{Hardware Parameters}

This section outlines the modelling assumptions when creating noise models from IBM fake backends.

We implicitly use all the assumptions of the two bath model outlined in ~\cite{lvov2025thermometry}, Section~A. In summary, we assume that the qubits only thermalise with two distinct temperature environments: the mixing chamber (MXC) and the environment.

All parameters in this model can be changed. In this paper, we choose to only vary temperature as the independent parameter of study. The rest of the parameters are either hardcoded beforehand or fit to calibration data at runtime.

To ensure the hardcoded parameters are still representative of the specific fake backend that we are modelling, for each parameter we choose one of three values, decided by the age of the backend. We characterise each backend as either modern, intermediate or legacy.

\noindent\rule{0.5\textwidth}{0.4pt}

The following parameters are hardcoded beforehand:

\begin{enumerate}
	\item $\gamma_\mathrm{MXC}/\gamma_1^0 = 0.9$ (coupling ratio)
	      \begin{itemize}
		      \item This is the ratio of how much of the qubit's relaxation couples to the mixing chamber (MXC) versus the residual electromagnetic environment
		      \item Lvov et al.~\cite{lvov2025thermometry}, Table~III, report experimental values of $0.60$--$0.85$ for custom devices; we assume $0.9$ as representative of IBM's professional superiority to standard lab equipment
	      \end{itemize}

	\item The default operational cryostat temperature, assumed to be $13mK$
	      \begin{itemize}
		      \item All calibration data is assumed to be collected at this temperature
	      \end{itemize}

	\item $\Delta = 2.88 \times 10^{-23}$~J (180~$\mu$eV) (superconducting energy gap)
	      \begin{itemize}
		      \item Note: This is the value for bulk aluminum value; IBM transmon electrodes and junctions use aluminum thin-films that can deviate slightly
		      \item With that being said, 180~$\mu$eV is standard in the superconducting qubit literature~\cite{catelani2011qp_relaxation}
	      \end{itemize}

	\item $\zeta = 5 \times 10^{-5}$ (subgap transparency)
	      \begin{itemize}
		      \item This characterizes the transparency of quasiparticle tunneling channels in the subgap regime; literature values range from $10^{-3}$ to $10^{-5}$~\cite{catelani2012qp_diffusion}
		      \item It is treated as a uniform constant across the chip, and thus a manufacturing constant
	      \end{itemize}
\end{enumerate}

\noindent\rule{0.5\textwidth}{0.4pt}

The following parameters are derived on a per qubit basis at runtime.

All per-qubit data mentioned below is retrieved directly from official IBM calibration data, pulled directly from the latest github commit.

\begin{enumerate}
	\setcounter{enumi}{4}
	\item $E_c$ (charging energy)
	      \begin{itemize}
		      \item In the transmon regime ($E_J/E_c \gg 1$), the anharmonicity approaches $\alpha \to -E_c/\hbar$~\cite{koch2007transmon}, Eq.~(2.5)
		      \item Since IBM reports anharmonicity $\alpha/2\pi$ in Hz:
		            \[
			            E_c = h \abs \alpha
		            \]
		      \item $\alpha$ represents qubit anharmonicity, and is obtained from calibration data
	      \end{itemize}

	\item $E_J$ (Josephson energy)
	      \begin{itemize}
		      \item We calculated it by inverting the transmon transition frequency $\hbar\omega_{ge} \approx \sqrt{8 E_J E_c} - E_c$~\cite{koch2007transmon}, Eq.~(2.5):
		            \[
			            E_J = \frac{(\hbar\omega_{ge} + E_c)^2}{8\,E_c}
		            \]
		      \item Qubit frequency is obtained from calibration data
	      \end{itemize}

	\item $\omega_p$ (plasma frequency)
	      \begin{itemize}
		      \item Sets the energy scale for quasiparticle-induced transition rates~\cite{catelani2011qp_relaxation}, using the same equation from before from ~\cite{koch2007transmon}:
		            \[
			            \omega_p = \frac{\sqrt{8\,E_J\,E_c}}{\hbar}
		            \]
	      \end{itemize}

	\item $R_n$ (normal-state junction resistance)
	      \begin{itemize}
		      \item From the Ambegaokar--Baratoff relation~\cite{ambegaokar1963tunneling}, inverted using $E_J = \pi\hbar\Delta/(4e^2 R_n)$:
		            \[
			            R_n = \frac{\pi\,\hbar\,\Delta}{4\,e^2\,E_J}
		            \]
	      \end{itemize}

	\item $N_e$ (effective number of junction channels)
	      \begin{itemize}
		      \item Following~\cite{catelani2012qp_diffusion}, Eq.~(15):
		            \[
			            N_e = \frac{1}{\zeta} \cdot \frac{g_T}{2\,g_K} = \frac{1}{\zeta} \cdot \frac{1}{2\,R_n\,g_K}
		            \]
		      \item where $g_K = e^2/h$ is the conductance quantum
		      \item $\zeta \sim 10^{-3}$--$10^{-5}$ is the subgap transparency, a global constant set by the fabrication process
		      \item Since $R_n$ varies per qubit (Step~4), $N_e$ varies per qubit
	      \end{itemize}

	\item $p_e$ (thermal excited-state population)
	      \begin{itemize}
		      \item First the probability of measuring $\ket{1}$ after preparing $\ket{0}$ is extracted for each qubit
		      \item The residual excited state population, $p_e$, as estimated as equal to this value.
		      \item This is likely a significant overestimation of $p_e$. Much of the readout error will not be due to excited state population, but simple measurement error.
		      \item This in turn will likely safely overestimate $T_{env}$.
	      \end{itemize}

	\item $T_\mathrm{env}$ (effective environment temperature) is estimated at runtime
	      \begin{itemize}
		      \item It is estimated per qubit from $p_e$ values (Step~6) and previously derived parameters
		      \item The median across all qubits is then taken
		      \item Derived from the two-bath model of~\cite{lvov2025thermometry}, Eq.~(14), in the low-$T_\mathrm{MXC}$ limit, as described in Section~\ref{sec:T_env-estimation}
	      \end{itemize}

	\item $\gamma_1^0$ (zero-temperature relaxation rate)
	      \begin{itemize}
		      \item At the operational temperature $T_\mathrm{op} \approx 13$~mK, quasiparticle contributions are negligible ($\gamma_\mathrm{QP}(T_\mathrm{op}) \approx 0$) and the MXC bath occupation vanishes ($n_\mathrm{MXC} \approx 0$)
		      \item This permits a closed-form inversion of the two-bath relaxation model~\cite{lvov2025thermometry}, Eqs.~(15) and~(27), as described in Section~\ref{sec:gamma0-derivation}
	      \end{itemize}

	\item $\gamma_{\varphi,\mathrm{base}}$ (base pure dephasing rate)
	      \begin{itemize}
		      \item At $T_\mathrm{op}$, quasiparticle dephasing is negligible ($\gamma_{\varphi,\mathrm{QP}}(T_\mathrm{op}) \approx 0$), so the standard decoherence decomposition~\cite{krantz2019guide} gives:
		            \[
			            \gamma_{\varphi,\mathrm{base}} = \frac{1}{T_{2,\mathrm{meas}}} - \frac{1}{2\,T_{1,\mathrm{meas}}}
		            \]
		      \item Clamped to $\gamma_{\varphi,\mathrm{base}} \geq 0$; a negative value would indicate $T_2 > 2T_1$, implying negligible pure dephasing
		      \item Note: IBM reports $T_2$ from Hahn echo measurements. Thus, $\gamma_{\varphi,\mathrm{base}}$ therefore captures only high-frequency dephasing sources. All $T_2$ predictions in this work correspond to echo coherence times
	      \end{itemize}

\end{enumerate}

From these parameters, temperature-dependent predictions for $T_1(T)$, $T_2(T)$ are computed as described in Section~\ref{sec:temperature-extrapolation}.

The following parameter is derived on a per gate basis at runtime:

\begin{enumerate}
	\setcounter{enumi}{13}
	\item $\epsilon_\mathrm{off}$ (gate error offset)
	      \begin{itemize}
		      \item First, gate infidelity at the default operational temperature is estimated using Eq.~\eqref{eq:F_N}, taking into account per qubit parameters
		      \item The linear difference between this estimated infidelity and the actual infidelity is stored and added as an offset
		      \item The physical interpretation of this is that this is the temperature-independent and thus temperature-stable component of gate error
		      \item Gates without a calibrated gate error (e.g., reset gates) are assigned decoherence-only error
	      \end{itemize}
\end{enumerate}

\subsection{Theory}
\subsubsection{Environment Temperature Estimation}
\label{sec:T_env-estimation}

At the default operational cryostat temperature, the Bose--Einstein occupation of the MXC bath at qubit frequencies is vanishingly small: $n(\omega_{ge}, T_\mathrm{op}) \approx 0$ at standard qubit frequencies. The two-bath effective occupation~\cite{lvov2025thermometry}, Eq.~(14), therefore simplifies to
\begin{equation}
	n_\mathrm{eff} \approx \frac{\gamma_\mathrm{env}}{\gamma_1^0}\, n(\omega_{ge}, T_\mathrm{env}),
\end{equation}
Note that $\gamma_0^1$ will cancel out, so is not needed.

We can then calculate $n_\mathrm{eff}$ (effective thermal photon occupation) from the standard equation of thermal occupation of a two-level system:
\begin{equation}
	n_\mathrm{eff} = \frac{p_e}{1 - 2\,p_e}.
\end{equation}
Inverting the Bose--Einstein distribution for $T_\mathrm{env}$:
\begin{equation}
	\label{eq:T_env}
	T_\mathrm{env} = \frac{\hbar\omega_{ge}}{k_B \ln\!\left(1 + \dfrac{\gamma_\mathrm{env}/\gamma_1^0}{n_\mathrm{eff}}\right)}.
\end{equation}
Combining the two equations, we get:
\begin{equation}
	\label{eq:T_env_combined}
	T_\mathrm{env} = \frac{\hbar\omega_{ge}}{k_B \ln\!\left(1 + \dfrac{\gamma_\mathrm{env}/\gamma_1^0}{p_e}\,(1 - 2\,p_e)\right)}.
\end{equation}
Therefore, $T_\mathrm{env}$ depends only on the global coupling ratio, the per-qubit frequency, and the corrected $p_e$.

Using this equation, we compute $T_\mathrm{env}$ per qubit and take the median. This uses the assumption that the electromagnetic environment temperature is spatially uniform across the chip.

We use $\gamma_\mathrm{MXC}/\gamma_1^0 = 0.9$.

% ------ Section: gamma_1^0 Derivation ------
\subsubsection{Zero-Temperature Relaxation Rate}
\label{sec:gamma0-derivation}

At $T_\mathrm{op} \approx 13$~mK, quasiparticle-induced relaxation is exponentially suppressed ($\gamma_\mathrm{QP} \propto e^{-\Delta/k_B T} \approx 0$). The total relaxation rate~\cite{lvov2025thermometry}, Eqs.~(15) and~(27), reduces to
\begin{equation}
	\frac{1}{T_{1,\mathrm{meas}}} = \gamma_1^0\,(2\,n_\mathrm{eff} + 1),
\end{equation}
where $n_\mathrm{eff}$ is computed from $T_\mathrm{env}$ (Section~\ref{sec:T_env-estimation}). Solving directly:
\begin{equation}
	\label{eq:gamma0}
	\gamma_1^0 = \frac{1}{T_{1,\mathrm{meas}}\,(2\,n_\mathrm{eff} + 1)}.
\end{equation}
This closed-form inversion replaces numerical optimization and is exact given the low-temperature approximations.

% ------ Section: Temperature Extrapolation ------
\subsubsection{Temperature-Dependent Predictions}
\label{sec:temperature-extrapolation}

With all per-qubit parameters from Steps~1--9, we compute the following temperature-dependent quantities at arbitrary cryostat temperature $T$.

\paragraph{Quasiparticle density.}
The thermal quasiparticle density follows~\cite{lvov2025thermometry}:
\begin{equation}
	\label{eq:xqp}
	x_\mathrm{QP}(T) = \sqrt{\frac{2\pi k_B T}{\Delta}}\,\exp\!\left(-\frac{\Delta}{k_B T}\right).
\end{equation}

\paragraph{Quasiparticle relaxation rate.}
From~\cite{lvov2025thermometry}, Eq.~(26), originally derived in~\cite{catelani2011qp_relaxation}:
\begin{equation}
	\label{eq:gamma_qp}
	\gamma_\mathrm{QP}(T) = \frac{\omega_p^2}{\pi\,\omega_{ge}} \left[ x_\mathrm{QP}\sqrt{\frac{2\Delta}{\hbar\omega_{ge}}} + 4\,e^{-\Delta/k_B T}\cosh\!\left(\frac{\hbar\omega_{ge}}{2k_B T}\right) K_0\!\left(\frac{\hbar\omega_{ge}}{2k_B T}\right) \right],
\end{equation}
where $K_0$ is the modified Bessel function of the second kind, and $\omega_p$ is per-qubit (Step~3).

\paragraph{Quasiparticle dephasing rate.}
From~\cite{lvov2025thermometry}, Eq.~(29), following~\cite{catelani2012qp_diffusion}:
\begin{equation}
	\label{eq:gamma_phi_qp}
	\gamma_{\varphi,\mathrm{QP}}(T) \sim 4\pi\,\frac{\omega_p^2}{\omega_{ge}} \sqrt{\frac{x_\mathrm{QP}^A}{N_e}},
\end{equation}
where $x_\mathrm{QP}^A = \exp(-\Delta/k_B T)$ and both $\omega_p$ and $N_e$ are per-qubit. We note that this expression is order-of-magnitude (as indicated by the ``$\sim$'' in the original reference); the numerical prefactor may differ by a factor of a few.

\paragraph{Relaxation time.}
\begin{equation}
	\label{eq:T1_T}
	T_1(T) = \frac{1}{\gamma_\mathrm{QP}(T) + \gamma_1^0\,(2\,n_\mathrm{eff}(T) + 1)},
\end{equation}
where $n_\mathrm{eff}(T) = (\gamma_\mathrm{MXC}/\gamma_1^0)\,n(\omega_{ge}, T) + (1 - \gamma_\mathrm{MXC}/\gamma_1^0)\,n(\omega_{ge}, T_\mathrm{env})$ follows the two-bath model~\cite{lvov2025thermometry}, Eq.~(14).

\paragraph{Coherence time.}
\begin{equation}
	\label{eq:T2_T}
	T_2(T) = \frac{1}{\dfrac{1}{2\,T_1(T)} + \gamma_{\varphi,\mathrm{base}} + \gamma_{\varphi,\mathrm{QP}}(T)}.
\end{equation}
As noted in Step~9, all $T_2$ predictions correspond to echo coherence times.

\paragraph{Gate fidelity.}
For an $N$-qubit gate of duration $t_\mathrm{gate}$, the decoherence-limited fidelity is~\cite{simbierowicz2024thermal_noise}, Eq.~(6), derived from~\cite{abad2022gate_fidelity}:
\begin{equation}
	\label{eq:F_N}
	F_N(T) = 1 - \frac{d\,t_\mathrm{gate}}{2(d+1)} \sum_{i=1}^{N} \left(\frac{1}{T_{1,i}(T)} + \frac{1}{T_{\varphi,i}(T)}\right),
\end{equation}
where $d = 2^N$ is the Hilbert space dimension, $T_{\varphi,i} = 1/(\gamma_{\varphi,\mathrm{base},i} + \gamma_{\varphi,\mathrm{QP},i}(T))$, and the sum runs over the constituent qubits of the gate. This formula assumes a local noise model acting independently on each qubit. Equation~\eqref{eq:F_N} captures only decoherence-limited infidelity.

Temperature-independent coherent error sources are accounted for in the $\epsilon_\mathrm{off}$, a linear factor calculated using IBM calibration data.

\begin{equation}
	\label{eq:coherent_floor}
	\epsilon_\mathrm{coh} = \epsilon_\mathrm{cal} - \epsilon_\mathrm{dec}(T_\mathrm{op}),
\end{equation}
where $\epsilon_\mathrm{cal}$ is the calibrated gate error from the backend properties. The total predicted gate error at temperature $T$ is then
\begin{equation}
	\label{eq:gate_error_total}
	\epsilon_\mathrm{gate}(T) = \min\!\left(1,\; \epsilon_\mathrm{dec}(T) + \epsilon_\mathrm{coh}\right).
\end{equation}
This additive decomposition of infidelities is a linear approximation; the exact result would require composing quantum channels. However, the approximation is accurate in the small-error regime ($\epsilon \sim 10^{-3}$--$10^{-2}$) where the product terms $\epsilon_\mathrm{dec}\,\epsilon_\mathrm{coh}$ are negligible. By construction, the predicted gate error recovers the calibrated value at $T_\mathrm{op}$.
